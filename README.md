# Codex Trace

本地 Codex 执行记录可视化，让每一步都有迹可循。

提供过程概览、事件时间线和关系图，直接读取本机记录，无需 LLM、API Key 或第三方 Python 包。

## 快速开始

克隆仓库后，在 PowerShell 中运行：

```powershell
git clone https://github.com/oonecab/codex-trace.git
cd codex-trace
.\start.ps1
```

脚本会启动服务并打开 [本地执行回放](http://127.0.0.1:8765)。它优先使用 Codex 随附的 Python；也可用已安装的 Python 3.10 以上版本，无需安装其他包。

```powershell
# 指定其他数据目录或端口
.\start.ps1 -CodexDataDirectory 'D:\CodexData' -Port 8766
# 只启动服务
.\start.ps1 -NoBrowser
# 跨平台入口，在本目录运行
python -m trace_viewer --open
```

保持启动终端打开。按 Ctrl+C 停止；如果默认端口已经占用，可以打开现有页面或换一个端口。

## 怎么看

- 左侧按项目、标题筛选会话，可包含已归档记录。按 `/` 聚焦会话搜索。
- 默认的“过程概览”按轮次展示规则汇总，将相邻的读取、修改、测试等操作折叠成阶段。点击阶段展开，使用轮次选择或“↓ 最新轮次”快速定位，也可展开全部阶段。
- “关系图”把动作、返回结果、文件及子代理连起来。可以切换轮次、按关联对象筛选，点击节点打开原始记录，点击连线查看关联依据；每页显示 12 个步骤。图内文字保持固定大小，不会随窗口变宽而放大；用右上角的 − / + 在 70%–130% 间缩放，点击百分比恢复 100%。窄窗口可以在图内横向滚动。
- 测试卡片识别 unittest / pytest 的终端汇总；同一轮中相同字面测试命令及工作目录会串成前后记录，方便对比结果。命令退出 0、测试输出报告通过、Codex 的完成陈述分别展示。
- “时间线”连续展示公开思考摘要、命令及输出预览、文件修改、网页搜索、工具和子代理活动。可按类别筛选或搜索标题和预览，色段可定位事件。“异常”包括非零退出码，不能直接等同于任务失败。
- “连续阅读”展开当前预览；完整命令、输出、补丁和原始字段在右侧详情中查看。按 Esc 关闭详情。
- 概览、时间线及详情共用字号和配色：主要正文 15px、轮次标题 16px，命令预览 13px；窄屏下控件自动换行，详情面板覆盖显示。
- 没有公开摘要的思考默认收起，可勾选“含无摘要思考”；不会补写或猜测思考正文。
- 自动刷新每 5 秒更新当前会话，时间线中的“↓ 最新”跳到末尾。它只展示已经保存到本地的内容，可能稍晚于 App 中的动作。

## 数据边界

直接只读本机 Codex 数据库和 rollout，不需要 OpenAI API Key、不下载本地模型、不调用评审模型、不上传会话。浏览器只连接本机服务。借鉴 OEB 分层整理记录的思路，实现“统一事件 → 规则卡片 → 可追溯关联 → 过程视图”。本项目独立实现，不复现 OEB 的模型裁判或能力评分。

连线依据是日志字段、记录顺序或字面命令匹配。它不判断“某条证据支持了某个结论”“某次修改修复了错误”等语义关系；复杂脚本无法细分时保留原命令。只展示源记录已有的公开摘要，不生成或猜测隐藏思考。

基础口径见 [执行记录与统计](docs/rules/records.md)，新增卡片、测试汇总和图关系的完整规则见 [过程整理规则](docs/rules/process.md)。版本兼容与模块结构见 [TECH.md](TECH.md)，运行设置见 [环境说明](docs/environments.md)。本地数据库属于 Codex 的内部格式，未来升级可能需要调整读取器。
